## 3.1. Характеристика объекта
- **Название программного продукта:** WinRAR (версия 6.24 для Windows).
- **Назначение:** Создание, управление и извлечение файлов из архивов (сжатие данных для экономии места и удобства передачи).
- **Основные функции:** 
  - Сжатие файлов в форматы RAR и ZIP.
  - Извлечение файлов из форматов RAR, ZIP, CAB, GZ, ACE, TAR и других.
  - Шифрование архивов (AES-256).
  - Создание многотомных и самораспаковывающихся (SFX) архивов.
  - Восстановление повреждённых архивов (записи для восстановления).
- **Предполагаемые пользователи:** Широкий круг пользователей ПК (от домашних пользователей до системных администраторов), работающих в ОС Windows.
- **Источник и версия:** Официальный сайт разработчика [rarlab.com](https://www.rarlab.com/), версия 6.24 (64-разрядная).

## 3.4. Исследование объекта
В ходе работы были применены следующие методы анализа:

1. **Анализ документации:** Изучена встроенная справка (`WinRAR.chm`) и официальный сайт. Документация подробно описывает форматы и параметры командной строки, но некоторые редкие коды возврата CLI не документированы.
2. **Динамический анализ и тестирование:** Проведено создание архивов RAR4 и RAR5, тестирование функции «Восстановление» на преднамеренно повреждённых файлах (изменение байтов в HEX-редакторе). Проверена реакция на нехватку места (выдаётся корректное предупреждение).
3. **Сравнительный анализ:** Проведено сравнение WinRAR 6.24 и 7-Zip 23.01 по скорости сжатия текстового набора данных (100 МБ) и итогового размера архива. WinRAR показал сопоставимую степень сжатия, но немного уступил в скорости на стандартных настройках.
4. **Ограничения исследования:** WinRAR является проприетарным программным обеспечением с закрытым исходным кодом. Поэтому **статический анализ кода**, **анализ структуры проекта** и **исследование исходного кода** не проводились. Выводы сделаны исключительно на основе наблюдаемого поведения (black-box testing) и доступной документации.

## 3.5. Выявленные проблемы
1. **Навязчивые уведомления в пробной версии.**  
   - *Критерий:* Удобство использования.  
   - *Подтверждение:* При каждом запуске GUI-версии появляется диалоговое окно с напоминанием о необходимости покупки лицензии.  
   - *Последствия:* Снижение пользовательского опыта, раздражение, возможность случайного закрытия программы вместо окна уведомления.  
   - *Рекомендация:* Сделать уведомление менее интрузивным (например, строкой статуса) или увеличить интервал между показами.

2. **Отсутствие явного индикатора прогресса при восстановлении сильно повреждённых архивов.**  
   - *Критерий:* Обработка ошибок.  
   - *Подтверждение:* При запуске функции «Восстановить» на архиве >1 ГБ с повреждёнными заголовками, интерфейс может «зависать» без прогресс-бара на этапе сканирования.  
   - *Последствия:* Пользователь может принудительно завершить процесс, посчитав программу зависшей, что прервёт успешное восстановление.  
   - *Рекомендация:* Добавить фоновый индикатор активности или текстовый лог процесса сканирования в реальном времени.

3. **Отсутствие встроенной проверки на вредоносное ПО.**  
   - *Критерий:* Безопасность.  
   - *Подтверждение:* WinRAR позволяет создать и распаковать архив, содержащий исполняемые файлы с известными сигнатурами вирусов, без каких-либо предупреждений (проверка перекладывается на сторонний антивирус).  
   - *Последствия:* Риск случайного запуска вредоносного ПО неопытным пользователем сразу после распаковки.  
   - *Рекомендация:* Добавить опциональную интеграцию с Windows Defender API или предупреждение при распаковке исполняемых файлов из архивов, скачанных из интернета (Zone.Identifier).

4. **Закрытость формата RAR5.**  
   - *Критерий:* Функциональная корректность / Совместимость.  
   - *Подтверждение:* Спецификация формата RAR5 не является полностью открытой. Некоторые сторонние инструменты (особенно на Linux/macOS) могут иметь ограничения при работе с новыми функциями RAR5.  
   - *Последствия:* Снижение кроссплатформенной совместимости по сравнению с открытыми форматами (ZIP, 7z).  
   - *Рекомендация:* Рассмотреть возможность публикации частичной спецификации RAR5 для улучшения поддержки в открытых проектах (как это было сделано для RAR4).

5. **Неполнота описания кодов возврата в справке CLI.**  
   - *Критерий:* Качество документации.  
   - *Подтверждение:* В разделе «Command line mode» описаны основные коды возврата (0, 1, 2, 3, 255), но отсутствуют описания для некоторых специфических ошибок (например, ошибки блокировки файлов антивирусом).  
   - *Последствия:* Затруднено написание надёжных скриптов автоматизации резервного копирования, так как скрипт не может однозначно интерпретировать причину сбоя.  
   - *Рекомендация:* Расширить раздел документации списком всех возможных кодов возврата и их причин.

## 3.7. Итоговое заключение
Проведённый комплексный анализ архиватора WinRAR (версия 6.24) показал, что продукт является высоконадёжным и функциональным инструментом для работы с архивами. Он корректно выполняет основные операции сжатия и шифрования, обладает развитым набором функций для восстановления данных. 

Однако в ходе исследования выявлены риски, связанные с удобством использования (навязчивые уведомления), недостаточной информативностью при длительных операциях восстановления и закрытостью формата RAR5, что влияет на экосистемную совместимость. 

**Ограничения исследования:** Анализ проводился методом «чёрного ящика» (black-box). Из-за отсутствия доступа к исходному коду WinRAR не применялись методы статического анализа кода, анализа структуры проекта и инструментального профилирования памяти. Оценка безопасности и производительности основана исключительно на наблюдаемом поведении и сравнительных тестах.

Рекомендуется использовать WinRAR для задач, требующих высокой степени сжатия и восстановления, но с учётом необходимости настройки скриптов автоматизации с резервированием на случай недокументированных ошибок CLI.
